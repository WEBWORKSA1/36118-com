36118: one number, four stories

Most numbers are only quantities. 36118 has a postal identity, a clean mathematical signature, a cultural reading and a place in a traded asset class. Here is each in turn.

1. A ZIP code with no residents

36118 is a U.S. ZIP code in Montgomery, Alabama, wholly inside Montgomery County and served by area code 334. It is classified as a unique ZIP code, meaning it routes mail to a single organisation rather than to homes. Directories associate it with the Gunter Annex area of Maxwell-Gunter Air Force Base.
